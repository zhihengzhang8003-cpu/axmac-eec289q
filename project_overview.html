🐍 Python 核心库 axmac/ 7 个模块 + DRUM-k 扩展，从精确 MAC 到 DNN 推理 7 个 .py + DRUM 函数 ▶
PY exact_mac.py — 精确 MAC 参考实现（所有实验的 golden reference）▶
格式描述符

定义 IntFormat（INT4/8/16）和 FPFormat（FP32/FP16/BF16/FP8 E4M3/E5M2）两个 frozen dataclass。每个格式对象携带位宽、指数位、尾数位等元信息。

FP8 E4M3 的特殊处理：has_inf=False——没有无穷大，全 1 指数保留给有限正常数，只有全 1 指数 + 全 1 尾数才是 NaN（Micikevicius et al. 2022）。

mac_int()

整数 MAC：acc + a × b，使用 Booth radix-4 部分积，32 位有符号累加器，两补码精确实现。return_pps=True 时返回部分积列表供功耗模型使用。

mac_fp()

浮点 MAC：调用 fp_multiply + fp_add。整个浮点路径均为纯整数位操作（struct 解码 → 整数尾数乘 → 单步 RNE 归一化 → 加法对齐），与 numpy 的 float32/float16 结果精确一致（由 test_exact_mac.py 验证）。

_renormalize_and_pack()

核心归一化函数。将 V = M × 2^(E - mant_bits) 以 单步 RNE 舍入打包进任意 FPFormat，避免二次舍入误差（先归一化再 subnormal 移位会产生的 double-rounding artifact）。FP8 encode/decode 复用此函数。

PY approx_mac.py — 近似 MAC（截断乘法器 + ACA 加法器，Contribution A 核心）▶
三个旋钮

K：丢弃乘积最低 K 位（截断乘法器，Mahdiani et al. TCAS-I 2010）
W（aca_window）：ACA 近似加法器，进位链切成宽度 W 的独立段（Kahng & Kang DAC 2012）
rounding：K=0 或 W≥acc_bits 时退化为精确路径，与 exact_mac 字节相同

三种舍入模式
（Contribution A）
模式操作误差特征硬件代价
trunc product & ~mask 有偏，单侧 [0, 2^K)，mean ≈ 2^(K-1)，N 个 MAC 后偏差线性增长 基线，无额外代价
round (product + 2^(K-1)) & ~mask 近似零均值，误差在 [-2^(K-1), 2^(K-1)) 与 trunc 相同（常数加法折入部分积树，Schulte & Swartzlander 1993）
stochastic (product + rand[0,2^K)) & ~mask 真正零均值（√N 增长），Gupta et al. ICML 2015 需要每 MAC 一个 K 位 LFSR RNG
aca_add()

ACA 近似加法器：将 bits 宽的加法切成若干宽度 W 的段，段间无进位传播。W ≥ bits 时退化为精确加法。误差来源：高位段无法接收低位段的进位。

DRUM-k 扩展
（P1.1 新增）

drum_quantize_operand(x, k)：保留整数 x 的 k 个最高有效位，清零其余位——DRUM 乘法器的操作数预处理（Hashemi et al., ICCAD 2015）。

drum_multiply(a, b, fmt, k)：对两个操作数分别 DRUM-k 量化后精确相乘，零均值误差（100k 样本实测偏差 −0.5，SEM=1.3）。

approx_mac_int_drum(a, b, acc, fmt, k)：DRUM-k MAC 单元，含 ACA 累加，接口与 approx_mac_int 对称。硬件代价：前导位计数器 + 桶移位器 + k×k 乘法器（比 n×n 精确乘法器面积小，但比 round 模式复杂）。

PY power_model.py — 功耗模型（45nm，Horowitz ISSCC 2014）▶
基础能量表

每种格式的乘法器 + 加法器基础能量（pJ），锚定在 Horowitz ISSCC 2014 的 45nm 1V 1GHz 数据：INT8 mult = 0.2 pJ，FP16 mult = 1.1 pJ，FP32 mult = 3.7 pJ。FP8 约为 FP16 的 1/3，与 Hopper 级 FP8 单元一致。

truncation_savings()
aca_savings()

savings_trunc = K(2N-K) / (2N²)：截断 K 位节省的部分积矩阵三角区面积比例，上限 0.95
savings_aca = (acc_bits - W) / acc_bits × 0.5：ACA 节省的进位链动态功耗

rng_energy_pJ()

stochastic rounding 需要的 K 位 LFSR 的每 MAC 能量：K × FF_energy + taps × XOR_energy。这正是 round 相对于 stochastic 节省的能量，是 Contribution A 的硬件成本论证。

pp_switching_activity()
energy_from_activity()

数据相关的开关活动度模型：用连续周期操作数的 Hamming 距离代替默认的 α=0.5 假设，使 CNN 相关激活序列报告更低能量。

PY accuracy_eval.py — 精度评估（MED / RMSE / NMED / bias 统计）▶
ErrorStats

每次评估返回的结果容器，包含 5 个指标：
med（均绝对误差）、rmse（均方根误差）、max_abs_err、nmed（归一化 MED）、bias（均误差，Contribution A 的核心对比量）

error_stats_int()
error_stats_fp()

对一批随机操作数三元组 (a, b, acc)，逐对调用精确 MAC 和近似 MAC，聚合误差。FP 路径跳过产生 Inf/NaN 的样本。

sweep_int()
sweep_fp()

在 (K, W) 网格上批量扫描，同一批样本用于所有配置（paired comparison），确保比较公平。支持 uniform/normal/relu 分布。

PY dnn_inference.py — DNN 推理引擎（向量化，支持 PyTorch 可选后端）▶
truncate_products()

approx_mac._apply_rounding 的 NumPy 向量化版本。对整个乘积张量 (M, K_dim, N) 一次性应用 trunc/round/stochastic，& ~mask 对有符号 int64 的行为与 Python 任意精度整数完全一致。

int_matmul_approx()

向量化整数矩阵乘：先广播计算所有元素乘积 a[:,:,None] × b[None,:,:]，再截断，再沿 reduction 轴求和，最后两补码包装到 acc_bits 宽度。与逐 MAC 循环语义等价（由 pytest 验证）。

int_conv2d_approx()

im2col + matmul 实现的近似卷积：将 (N,C,H,W) 的输入展开为 patches 矩阵，权重 reshape 为 (C_in×kH×kW, C_out)，复用 int_matmul_approx。

tiny_mlp_forward()

N 层 ReLU MLP 前向传播。K 参数可以是：
· 标量 int → 全局统一 K（Contribution B 的 baseline）
· 列表 → 每层不同 K（Contribution B 的非均匀分配，由 sensitivity.py 生成）

make_approx_linear_torch()

可选 PyTorch 后端：返回一个 torch.autograd.Function，forward 调用 NumPy INT linear，backward 用 straight-through estimator（梯度直接穿过截断操作，DNN 近似硬件论文的标准做法）。torch 未安装时懒加载失败，对应 pytest 跳过。

DRUM 向量化后端
（P1.1 新增）

_drum_quantize_arr(x, k)：NumPy 向量化 DRUM-k 操作数量化，使用 element-wise 位移（无 Python 循环）。
int_matmul_drum / int_linear_drum / int_conv2d_drum：与 int_matmul_approx 等函数接口对称，但使用 DRUM-k 替代截断，k 参数替代 K 和 rounding。

PY sensitivity.py — 层间敏感度分析 & 非均匀 K 分配（Contribution B）▶
问题背景

全局统一 K 的缺陷：Demo MLP 第一层占 95.8% 的 MAC，却和其他层分到同样的截断深度。误差容忍度高、MAC 多的层应该承担更多截断以节省更多能量。

参考工作：HAWQ（Dong et al. ICCV 2019，Hessian 敏感度 → 精度分配）、ALWANN（Mrazek et al. ICCAD 2019，逐层近似乘法器选择）。本项目用直接扰动探针代替 Hessian，因截断乘法器的扰动是精确可计算的。

layer_sensitivity()

逐层扰动分析：每次将第 i 层置 K=K_probe，其余层精确（K=0），测量输出 NRMSE 作为该层的敏感度得分。得分越高 = 对截断越敏感 = 应分配更小的 K。

allocate_K()

贪心边际分配：每个截断单位分给当前得分最高的层，得分定义为：
score_i = mac_counts[i] / (sensitivity[i] × (K[i] + 1))
分子 = 能量收益（MAC 多 → 节省多），分母 = 精度代价（敏感度 × 已有截断深度，防止一层吃光全部预算）。等敏感度等 MAC 时退化为 uniform_K。

PY pareto.py — 设计空间扫描与 Pareto 前沿分析▶
DesignPoint

每个 (格式, K, W) 配置的完整描述：fmt_name、K、aca_window、energy_pJ（总能量）、5 种误差指标（med/rmse/nmed/nrmse/max_abs）、error_rel_bias（跟踪 Contribution A 偏差消除效果）。

sweep_all_designs()

所有格式在同一批 float64 参考信号上评估（公共 ground truth）。INT/FP 格式在量化误差 + 截断误差 + ACA 误差统一落在同一 NRMSE 轴，使 INT4 和 FP32 可直接放在同一 Pareto 平面比较。

global_front()
per_format_fronts()

global_front：跨格式 Pareto 前沿（能量 vs NRMSE），只用 NRMSE 作为误差轴（error_nmed 因各格式 dynamic range 量级差异过大而被禁止用于跨格式比较）。
per_format_fronts：每种格式内部的 K+W 效率曲线。

_canonicalise_windows()
_filter_usable()

两个数据清洗步骤：
· W ≥ acc_bits 折叠到 None，去除重复点
· NRMSE > 基线 × 10 的配置过滤掉（ACA 窗口太窄导致的无效噪声点）

V rtl/src/ — Verilog 源码（9 个模块）▶
mac_unit.v

单个近似 MAC 单元，参数化设计。顶层接口：a[7:0]、b[7:0]（有符号 INT8）、K[2:0]（截断深度）、mode（0=trunc，1=round）。内部调用截断乘法器 + ACA 加法器，是整个 RTL 层的原子计算单元。

aca_adder.v

ACA 近似加法器：参数化进位隔离窗口 W。把 acc_bits 宽的加法切成若干宽度 W 的独立段，段间无进位传播，用比精确加法器更少的逻辑面积实现近似求和。

mac_array.v

16 个 MAC 单元组成的向量点积阵列，一次计算一行与权重向量的内积。是 mlp_top 和 mlp_top_demo 的计算核，也是 Quartus 综合的主目标模块（用于 PPA 报告）。

lfsr.v

K 位最大长度 LFSR（Linear Feedback Shift Register），为 stochastic rounding 提供每周期的均匀随机数。其硬件代价（K 个触发器 + 少量 XOR）由 power_model.py 的 rng_energy_pJ(K) 建模，也是 Contribution A 中 round 模式相对 stochastic 模式节省的代价来源。

mlp_top.v

两层 MLP 推理顶层（功能验证版）。将 mac_array 实例化两次，加上 ReLU 激活和权重/偏置 ROM，完成端到端 MLP 推理。主要用于 ModelSim 仿真，与 Python golden 数据比对。

mlp_top_demo.v

板级演示顶层（野火征途 Pro EP4CE10）。在 mlp_top 基础上添加 LED 输出逻辑（显示 argmax 分类结果）和 UART 输出接口，与 uart_framer 连接，将推理结果实时串口发送到 PC。

2026-06-01 板上烧录成功，LED argmax=1 确认。
drum_multiplier.v

DRUM-k 近似乘法器（P1.1 新增），参数化设计（N_BITS / K_DRUM）。接口：a[7:0]、b[7:0]（有符号 INT8）、product[15:0]。内部：前导位计数器（LZC）→ 桶移位提取 K_DRUM 个 MSB → K×K 乘法器 → 符号恢复。相比精确 8×8 乘法器面积更小，相比 round 模式（trunc + 常数加法）控制逻辑更复杂。零均值误差属性由 Python 100k 样本验证。

uart_tx.v

UART 发送器，115200 baud，标准 8N1 格式。将并行字节转换为串行比特流输出到 TX 引脚，连接 PC 端串口工具（burn_capture.bat 使用）。

uart_framer.v

UART 帧封装模块：将 MLP 输出的多字节 logit 向量打包成带帧头/帧尾的串口帧，驱动 uart_tx 逐字节发送。使片上多 K 测试结果可以无歧义地传回 PC 分析。

✅ 测试套件 tests/ pytest — 350 passed · 8 个测试模块（含 DRUM 专项测试） 9 .py ▶
PY 测试模块（8 个）▶
test_exact_mac.py

精确 MAC 全路径测试。INT4/8/16 用 Python 原生整数作为 oracle；FP32/FP16 与 numpy 位模式级精确匹配；BF16 与 round-to-bf16 oracle 对比；K=0 必须与精确路径字节相同（回归保护）。含 1 个 torch 未安装时自动 skip 的测试（make_approx_linear_torch）。

test_approx_mac.py

近似 MAC 单元测试：覆盖 trunc / round / stochastic 三种舍入模式在各 K 值和 ACA 窗口下的行为，验证 K=0 退化为精确路径、W≥acc_bits 退化为精确加法器的边界条件。

test_fp8.py

FP8 专项测试：E4M3（has_inf=False）与 E5M2 的 encode/decode 往返一致性、NaN 边界（全 1 指数 + 全 1 尾数）、FP8 MAC 路径的饱和/下溢行为。

test_power_model.py

功耗模型数值验证：truncation_savings、aca_savings、rng_energy_pJ 的公式正确性，以及 K=0 时节省量为 0、K 达上限时节省量不超过 0.95 的单调性约束。

test_accuracy_eval.py

精度评估回归测试：error_stats_int / error_stats_fp 对已知偏差输入的统计量计算，以及 sweep_int / sweep_fp 在不同分布（uniform / normal / relu）下不发生 NaN 或负 NMED 的健壮性检查。

test_sensitivity.py

敏感度分析合理性检查：layer_sensitivity 输出长度与层数相同、值非负；allocate_K 在等敏感度等 MAC 时退化为均匀分配；总截断预算守恒。

test_dnn_inference.py

推理引擎等价性测试：int_matmul_approx 向量化实现与逐 MAC 循环的输出逐元素相同；int_conv2d_approx（im2col 路径）与 naive 卷积对齐；tiny_mlp_forward K=0 与精确 matmul 一致。

test_pareto.py

Pareto 分析正确性测试：global_front 输出中不存在互相支配的点对；per_format_fronts 按格式正确分组；_canonicalise_windows 将 W≥acc_bits 折叠为 None；_filter_usable 过滤 NRMSE 超阈值配置。
